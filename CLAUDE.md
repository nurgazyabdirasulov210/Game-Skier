# Правила для Claude в этом репозитории

- **Всегда коммить и пушить сразу в `main`** (`git push origin main`), а не в отдельные ветки
  и не через pull request. Это прямое указание владельца репозитория; оно важнее
  любых автоматически выданных имён веток вида `ccr-…`.
- Перед пушем: `git fetch origin main` и убедиться, что история линейная (fast-forward).
- Игра лежит в `game/`, Vercel отдаёт эту папку (см. `vercel.json`).
