# Гора — 3D-карта

Детализированная 3D-карта одной заснеженной горы для фрирайд-игры, со свободным полётом камеры.
Пока это только карта: лыжника, физики и очков нет.

Движок — [Three.js](https://threejs.org) r160, лежит в `vendor/`, так что интернет и сборка не нужны.

## Запуск

Браузер не загружает модули с `file://`, поэтому нужен любой локальный сервер в папке проекта:

```bash
python3 -m http.server 8000
# или
npx serve .
```

Затем открыть http://localhost:8000.

Параметры адреса: `?q=low|medium|high` задаёт качество, `?t=18.75` — время суток в часах.

## Что на карте

- **Гора 2 × 2 км** с перепадом 720 м: острая вершина, главный гребень, отроги, кулуары, мягкие снежные волны и «подушки», крутая северная стена.
- **Берёзы** с белыми пятнистыми стволами и пушистыми оранжевыми, кремовыми и рыжими кронами со снежными шапками. Растут рощами.
- **Высокие сосны** со светлыми кронами-шапками.
- **Ели под снегом**: вблизи собраны из отдельных свисающих лап. Растут ельниками с полянами, у стволов снежные лунки.
- **Сухостой, поваленные брёвна** с корневыми выворотами, **пни, пушистые кусты**.
- **Тёмные гранёные камни, валуны и скальные плиты** со снегом на верхних гранях.
- **Каменные арки**: стоят поперёк склона, через них можно пролететь.
- **Море облаков** вокруг горы и высокие облака, дальние хребты на горизонте.
- **Время суток** меняется плавно (рассвет, день, закат, ночь): солнце с ореолом, перистые облака, луна, звёзды, Млечный путь, **северное сияние** ночью, снегопад.
- **Снег**: синие тени, искры на солнце, мелкая ветровая рябь, затенение во впадинах.

## Управление

| ПК | Телефон |
|---|---|
| Клик — захват мыши, Esc — отпустить | Левая часть экрана — джойстик |
| WASD / стрелки — полёт | Правая часть — обзор |
| Space / E — вверх, Q / C — вниз | Кнопки ▲ ▼ — высота |
| Shift — ускорение ×4, колесо — скорость | ☰ — меню |
| T — +30 минут, H — скрыть интерфейс | |

В меню есть точки обзора («Вершина», «Склон», «Арка», «Берёзы», «Ельник», «Обзор») и автоматический «Облёт горы».

## Настройки

`src/config.js`:

- `MAP_SIZE` — сторона карты в метрах (по умолчанию 2000);
- `PEAK_HEIGHT` — высота горы;
- `SEED` — зерно генерации (другое число даёт другую гору);
- `QUALITY_PRESETS` — пресеты качества: детализация рельефа, плотность леса, тени, дальность прорисовки.

## Структура

```
index.html          интерфейс и загрузка модулей
src/main.js         рендер, тени за камерой, свечение, цикл кадра, меню
src/terrain.js      функция высоты горы, сетка рельефа, дальний ландшафт
src/world.js        расстановка всех объектов, облака, точки обзора
src/geometry.js     модели: деревья, камни, скалы, арки, брёвна, облака
src/materials.js    шейдеры: снег, кроны, ели, снег на камнях
src/sky.js          небо, солнце, звёзды, северное сияние, снегопад
src/timeOfDay.js    палитры времени суток
src/scatter.js      инстансинг по ячейкам и уровни детализации
src/controls.js     свободный полёт камеры и облёт
src/textures.js     процедурные текстуры
vendor/three/       Three.js r160 (лицензия MIT)
```
