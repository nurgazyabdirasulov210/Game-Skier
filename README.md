# ПУХ — фрирайд по целине

Оригинальная браузерная игра про фрирайд на лыжах по глубокому снегу в открытом мире.
Three.js r160 лежит в `game/vendor`, сборка не нужна.

## Запуск

```
cd game && python3 -m http.server 8000
# открыть http://localhost:8000
```

Параметр `?q=mid` или `?q=low` снижает качество графики для слабых машин.
Vercel отдаёт папку `game/` (см. `vercel.json`).

## Что есть

- Бесконечный склон: гребни, кулуары, роллеры, уступы с карнизами, по которым удобно улетать.
- Деформируемый снег: глубокие траншеи от лыж с бортиками и бороздками, ямы на месте
  приземлений и падений. Из‑под лыж летят комья, часть из них остаётся вдоль следа.
- Лес: пушистые лиственные кроны, высокие заснеженные ели, валуны, брёвна,
  каменные ворота. Пролёт через ворота даёт очки.
- Погода: «Ясный день», «Полярная ночь» с северным сиянием, «Закат».
- Трюки: прыжки, вращения 180–1440, сальто вперёд и назад, захваты, свитч,
  «впритирку» мимо деревьев, параплан. Комбо с множителем и таймером.
- Камеры: сзади, издалека, от первого лица.
- Клавиатура, геймпад, сенсорное управление.

## Управление

| Клавиши | Действие |
|---|---|
| A / D | повороты, вращение в воздухе |
| W / S | разгон и торможение; в воздухе сальто |
| Пробел | зажать и отпустить: прыжок |
| Shift, J / K / L | захваты |
| F | параплан в полёте |
| C | камера |
| R | вернуться на трассу |
| M | звук |
| Esc | меню |
