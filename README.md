# Гора — 3D-карта

Детализированная 3D-карта одной заснеженной горы для фрирайд-игры, со свободным полётом камеры.
Пока это только карта: лыжника, физики и очков нет.

Движок — [Three.js](https://threejs.org) r160, лежит в `vendor/`, так что интернет и сборка не нужны.

## Запуск

Браузер не загружает модули с `file://`, поэтому нужен любой локальный сервер в папке проекта:

```bash
python3 -m http.server 8000
# или
npx serve .
```

Затем открыть http://localhost:8000.

Параметры адреса: `?q=low|medium|high` задаёт качество, `?t=18.75` — время суток в часах.

## Что на карте

Стиль — стилизованный, «мультяшный», как в референсе: гладкие формы, чистый снег, насыщенные цвета, крупные цветные тени, сильное свечение.

- **Гора 2 × 2 км** с перепадом 720 м: округлая вершина, широкие ложбины вдоль склона, плавные валы поперёк склона, мягкие снежные дюны. Мелкого шума нет.
- **Берёзы**: тонкие белые стволы с крупными чёрными пятнами и пушистые шары крон на верхушках (оранжевые, рыжие, изредка кремовые) со снежными шапками. Кроны собраны из спрайтов, развёрнутых к камере, поэтому по краю шара виден мех.
- **Высокие сосны**: тёмные наклонные стволы со светлыми пушистыми шапками на ветках.
- **Ели** из снежных зубчатых ярусов, ельники с полянами.
- **Толстые берёзовые брёвна** в снегу, **пни, сухостой, пушистые кусты**.
- **Тёмно-синие гранёные глыбы и клинья.**
- **Каменные ворота** с овальным проёмом стоят поперёк склона, через них можно проехать.
- **Время суток** (рассвет, день, закат, ночь):
  - днём солнце за спиной у смотрящего вниз по склону, тени тянутся к зрителю;
  - на закате бирюзово-оранжевое небо, лучи от солнца и фиолетовый снег;
  - ночью кобальтовый снег, звёзды, луна, северное сияние и снегопад.
- **Дымка**: у земли плотнее, на высоте прозрачнее, чтобы с воздуха была видна вся гора.

## Управление

| ПК | Телефон |
|---|---|
| Клик — захват мыши, Esc — отпустить | Левая часть экрана — джойстик |
| WASD / стрелки — полёт | Правая часть — обзор |
| Space / E — вверх, Q / C — вниз | Кнопки ▲ ▼ — высота |
| Shift — ускорение ×4, колесо — скорость | ☰ — меню |
| T — +30 минут, H — скрыть интерфейс | |

В меню есть точки обзора («Вершина», «Склон», «Арка», «Берёзы», «Ельник», «Обзор») и автоматический «Облёт горы».

## Настройки

`src/config.js`:

- `MAP_SIZE` — сторона карты в метрах (по умолчанию 2000);
- `PEAK_HEIGHT` — высота горы;
- `SEED` — зерно генерации (другое число даёт другую гору);
- `QUALITY_PRESETS` — пресеты качества: детализация рельефа, плотность леса, тени, дальность прорисовки.

## Структура

```
index.html          интерфейс и загрузка модулей
src/main.js         рендер, тени за камерой, свечение, цветокоррекция, дымка, меню
src/terrain.js      функция высоты горы, сетка рельефа, дальний ландшафт
src/world.js        расстановка всех объектов, точки обзора
src/geometry.js     модели: деревья, кроны-спрайты, камни, ворота, брёвна
src/materials.js    шейдеры: снег, кроны-спрайты и их тени, ели, снег на камнях и брёвнах
src/sky.js          небо, солнце и лучи, звёзды, северное сияние, снегопад
src/timeOfDay.js    палитры времени суток
src/scatter.js      инстансинг по ячейкам и уровни детализации
src/controls.js     свободный полёт камеры и облёт
src/textures.js     процедурные текстуры
vendor/three/       Three.js r160 (лицензия MIT)
```
