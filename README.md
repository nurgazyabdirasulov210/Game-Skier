# ЦЕЛИНА — фрирайд по нетронутому снегу

Оригинальная браузерная 3D-игра про фрирайд (three.js, собственные шейдеры, без сборки).

**Играть:** откройте `game/index.html` через любой статический сервер (`python3 -m http.server` в папке `game`) или задеплойте на Vercel: `vercel.json` отдаёт папку `game/`.

## Что внутри
- Бесконечный процедурный склон: кулуары, подушки, скальные сбросы, естественные трамплины. Высота считается одной и той же функцией на GPU и CPU.
- Глубокий пухляк: за лыжником остаётся настоящая траншея с брустверами и рваными стенками, приземления оставляют кратеры, падения — борозды.
- Комья и снежная пыль летят из-под лыж, сильнее в поворотах и при торможении.
- Смена времени суток: рассвет, день, закат, сумерки, ночь со звёздами и северным сиянием. Каскадные тени, туман в цвет неба, bloom, размытие на скорости.
- Лес меняется по биомам: ельник, сосновый бор с берёзами, открытые поля, альпика с камнями и арками.
- Трюки: винты, сальто, грабы, свитч, дропы, скольжение по брёвнам, пролёт под арками, «впритирку» у деревьев, параплан. Комбо с множителем, рекорд сохраняется.
- Камеры: сзади, низкая, от первого лица, дрон.
- Клавиатура, геймпад и сенсорное управление; три уровня графики и адаптивное разрешение.

## Управление
| Клавиша | Действие |
|---|---|
| A / D | поворот, в воздухе — винт |
| W | стойка «яйцо» (на малой скорости — толчок палками), в воздухе — сальто вперёд |
| S | торможение, в воздухе — сальто назад |
| Пробел (держать и отпустить) | прыжок |
| Shift | граб |
| F | параплан (в прыжке) |
| C | камера |
| T | перемотать время суток |
| R | подняться после падения |
| H | скрыть интерфейс |
| Esc | пауза |
