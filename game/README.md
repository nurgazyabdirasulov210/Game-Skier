# ПОРОША — фрирайд в открытом мире

Оригинальная стилизованная 3D-игра про фрирайд на лыжах по бесконечному
процедурному склону. WebGL2 + three.js (лежит в `vendor/`), все шейдеры свои.
Работает в браузере на ПК и телефоне.

## Запуск

ES-модулям нужен HTTP-сервер:

```bash
cd game
python3 -m http.server 8000
# открыть http://localhost:8000
```

Параметры адреса: `?q=low|medium|high` — качество графики, `?seed=123` — другая
гора, `?tod=0.6` — время суток (0…1).

## Управление

| Клавиши | На снегу | В воздухе |
|---|---|---|
| `A` `D` / `←` `→` | повороты (карвинг) | вращения 180°, 360°, 540°… |
| `W` / `↑` | стойка «яйцо», толкаться палками | фронтфлип |
| `S` / `↓` | тормоз | бэкфлип |
| `Пробел` | держать — присед, отпустить — прыжок | — |
| `Shift` / `E` | — | грэб (с `W`/`S`/`A`/`D` — разные) |
| `G` / `Q` | — | раскрыть/сложить параплан |
| `C` | камера: сзади / от первого лица / дрон | |
| `T` · `O` | время суток · костюм | |
| `R` · `H` · `M` · `Esc` | встать · скрыть HUD · звук · меню | |

Геймпад: стик — руль/трюки, A — прыжок, X/RT — грэб, LT — тормоз, Y — параплан,
RB — камера, LB — время суток. На телефоне: левая часть экрана — джойстик,
справа — кнопки «Прыжок», «Грэб», «Тормоз», «Крыло».

## Что внутри

- **Открытый мир без границ.** Склон генерируется чанками 64×64 м вокруг игрока
  в отдельных Web Worker'ах с LOD (0,5 м у ног → 8 м на горизонте) и «юбками»
  против щелей. Гребни и кулуары, скальные пояса со сбросами, природные
  трамплины, бугры, пиллоу.
- **Деформируемый снег.** Высотное поле (render target, следует за игроком,
  сдвигается целыми текселями) — лыжи прорезают в целине траншею с рыхлыми
  отвалами по краям, падение оставляет воронку. Вершины рельефа смещаются,
  нормали пересчитываются попиксельно, стенки колеи «комковатые».
- **Пудра.** Облака снежной пыли (мягкие билборды с подсветкой контровым
  светом) и комья снега, которые летят, бьются о склон, рассыпаются и тают.
- **Шейдеры.** Тун-снег с цветными тенями, блёстки, ветровые застружки, скалы
  на крутых участках; ели со снежными шапками, золотые лиственницы,
  «снежные призраки», сухостой; ветер в кронах; небо с облаками, звёздами,
  луной и северным сиянием; кольцо дальних гор; высотный туман.
- **Пост-обработка (HDR).** Bloom, солнечные лучи, радиальное размытие на
  скорости, хроматическая аберрация, ACES-тонмаппинг, грейдинг под время суток,
  виньетка, зерно.
- **Цикл дня и ночи**: рассвет, утро, день, золотой час, закат, сумерки, ночь
  (налобный фонарь, снегопад, сияние, светящиеся окна избушек).
- **Физика**: карвинг с кантами, торможение, сопротивление целины, отрыв
  с перегибов по-честному (по кривизне и скорости), ноги гасят мелкие бугры,
  прыжок с зарядом, вращения/сальто/грэбы, проверка приземления, падения.
- **Параплан**, **слайды по брёвнам**, **флажковые ворота** (множитель),
  **кристаллы**, «впритирку» у деревьев, очки за свежую пудру и скорость.
  Комбо копится, пока делаешь трюки подряд; падение сжигает комбо.
- **Мир**: старая канатная дорога с движущимися креслами (просеки в лесу),
  избушки с дымом из труб, камни, пни, брёвна.
- **Персонаж**: собран из примитивов, ноги и руки на двухзвенном IK, наклон
  в повороте, втыкание палок, позы в воздухе, кувырки; шарф на верлет-физике.
- Процедурный звук и эмбиент-музыка (WebAudio), геймпад и тач, адаптивное
  разрешение по FPS.

## Структура

```
game/
  index.html         HUD, меню, тач-кнопки, стили
  src/main.js        игровой цикл, связка систем, качество, время суток
  src/terrain.js     функция высоты, трамплины, скалы, расстановка объектов
  src/terrainWorker.js  сборка геометрии чанков (в воркере)
  src/world.js       стриминг чанков, LOD, инстансинг леса, коллайдеры
  src/trail.js       деформация снега (render target)
  src/materials.js   шейдеры снега, деревьев, пропсов
  src/shaderlib.js   общие uniform'ы и GLSL (туман, фонарь, шум)
  src/sky.js         небо, дальние горы
  src/palette.js     палитры времени суток
  src/player.js      физика и трюки
  src/skier.js       модель и анимация персонажа, параплан
  src/particles.js   пудра, комья, снегопад, дым
  src/post.js        пост-обработка
  src/camera.js      камеры
  src/score.js       очки и комбо
  src/hud.js, input.js, audio.js
  vendor/            three.js r160 (MIT)
```
