# ПУДРА — фрирайд в открытом мире

Стилизованная 3D-игра про фрирайд на лыжах в бесконечном процедурном мире.
Написана на WebGL (three.js) с собственными шейдерами, запускается в любом
современном браузере — на ПК и на телефоне.

## Запуск

ES-модулям нужен HTTP-сервер (открыть `index.html` двойным кликом не получится):

```bash
cd game
python3 -m http.server 8000
# открыть http://localhost:8000
```

three.js лежит в `vendor/`, так что интернет не нужен (кроме шрифтов — без них
просто будет системный шрифт).

## Управление

| Клавиши | На снегу | В воздухе |
|---|---|---|
| `A` `D` / `←` `→` | повороты (карвинг) | вращение (180°, 360°, 540°…) |
| `W` / `↑` | стойка «яйцо», разгон на пологом | фронтфлип |
| `S` / `↓` | торможение | бэкфлип |
| `Space` | держать — присед, отпустить — прыжок | — |
| `Shift` / `E` | — | грэб |
| `C` | камера: сзади / кино / от первого лица | |
| `T` | следующее время суток | |
| `O` | сменить костюм | |
| `R`, `M`, `Esc` | подняться, звук, пауза | |

На телефоне: левая половина экрана — руль (свайп влево/вправо), справа — кнопки.

## Что внутри

- **Открытый мир** — рельеф генерируется чанками вокруг игрока бесконечно в любую
  сторону: долины, гребни, кулуары, бугры, трамплины с флажками, лес с полянами,
  камни, брёвна, каменные ворота, светящиеся кристаллы.
- **Шейдеры** (`src/shaders.js`): тун-освещение снега с цветными тенями,
  ветровые застружки, блёстки; пушистые кроны с просвечиванием на закате;
  береста; снежные шапки; небо с солнцем, облаками и звёздами; туман в цвет неба.
- **Пост-обработка** (`src/post.js`): радиальный блюр на скорости, лучи от
  солнца, свечение, хроматическая аберрация, виньетка, зерно.
- **Цикл дня и ночи** — рассвет, день, золотой час, закат, синие сумерки, ночь
  со снегопадом.
- **Физика** (`src/player.js`): полная гравитация по рельефу, кант гасит боковое
  скольжение, отрыв на перегибах происходит сам, прыжок с зарядом, вращения
  и сальто, проверка приземления, падения и кувырки.
- **Очки**: вращения, сальто, грэбы, полёт, свитч, ворота, «впритирку» у деревьев,
  кристаллы. Трюки, сделанные подряд, копятся в комбо с множителем; падение
  сжигает комбо. Рекорд сохраняется в браузере.
- **Анимация лыжника** — процедурная: присед с двухзвенными ногами, наклон в
  повороте, работа руками и палками, поза в воздухе, грэб, кувырок при падении.
- Пыль из-под лыж, следы на снегу, звук ветра и снега (WebAudio), сенсорное
  управление, автоподстройка качества под FPS.

## Структура

```
game/
  index.html       HUD, меню, сенсорные кнопки
  src/main.js      игровой цикл, камера, связка систем
  src/terrain.js   функция высоты, трамплины
  src/world.js     стриминг чанков, лес, объекты, коллайдеры
  src/player.js    физика и трюки
  src/skier.js     модель и анимация персонажа
  src/shaders.js   материалы
  src/palette.js   время суток
  src/fx.js        частицы, следы, снегопад
  src/post.js      пост-эффекты
  src/hud.js       очки, комбо, всплывашки
  src/input.js     клавиатура и тач
  src/audio.js     процедурный звук
  vendor/          three.js r160 (MIT)
```
